# viacruz Visitenkarten

Version 0.2.2

## v0.2.2
- Eigene Live-Kameraansicht in der PWA
- Visitenkartenrahmen ist bereits während des Fotografierens sichtbar
- Nur der Bereich innerhalb des Rahmens wird als Kartenfoto übernommen und ausgewertet
- Kamerawechsel Vorder-/Rückkamera möglich
- Erweiterte OCR-Bereinigung für isolierte Zeichen-, Zahlen- und Symbolreste
- Echte Sätze der Kartenrückseite bleiben erhalten
- QR-Code, Stichwörter und anklickbare Kontaktaktionen bleiben erhalten

Die Kamera benötigt HTTPS und die Kameraberechtigung des Browsers.
